# My First Website — Vivi

## 使用方法
1. 解压 `vivi_website_redesign.zip`。
2. 保持所有文件和图片在同一个文件夹中。
3. 用 VS Code 打开该文件夹，建议使用 Live Server 预览 `index.html`。
4. 每个页面只通过顶部的 Home / Quotes / Project / Contact 导航切换。

## 文件说明
- `index.html`：简洁首页、Vivi / CS3 介绍、原来的微信插图。
- `quotes.html`：原来的 9 条名人名言与署名。
- `project.html`：五个简洁项目想法，第一个是了解狗狗的网站。
- `contact.html`：邮箱 `chenky1015@163.com`。
- `styles.css`：全站简约样式、布局、响应式导航和动画。
- `nav.js`：导航高亮、手机菜单，以及更浓郁、流动的颜料式鼠标拖尾。
- `dog.svg`：原狗狗 Logo，请不要替换或移动。
- `plain-image-32x31-69b9d3-rectangle.png`：原纯色 favicon，请不要替换或移动。
- `微信图片_20251215001331_40_8.jpg`：原微信插图，请不要替换或移动。

鼠标颜料效果在支持鼠标/触控板的电脑上启用；手机和开启系统“减少动态效果”的设备会关闭。网页字体从 Google Fonts 加载，离线时会使用系统字体。
